# Hooks Basic

A minimal React + Vite + Tailwind site for practicing custom hooks.

## Run it

```
npm install
npm run dev
```

## Where to write code

The three files below are intentionally left blank (with TODO comments) —
that's the hooks practice:

- `src/hooks/useCounter.js` — state + simple updater functions
- `src/hooks/useToggle.js` — boolean state
- `src/hooks/useFetch.js` — state + `useEffect` for data fetching

Each hook is already wired up to a demo component in `src/components/`,
so as soon as you implement one, its section on the page comes alive.
